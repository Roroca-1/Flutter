# 轻书架

轻书架官方 Flutter 客户端的功能拓展版本。目前面向 Android平台进行测试，其他平台需要自行编译测试。


## 开发

```bash
flutter pub get
flutter run -d <device>
```

注入刷新令牌：

```bash
flutter run --dart-define=REFRESH_TOKEN=<refresh token>
```
